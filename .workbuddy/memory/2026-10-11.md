1. **AI 引擎**：内置 TypeScript 自研引擎（alpha-beta + 置换表），放弃 Pikafish（原生进程在 Web/小程序不可用，GPL-3.0）

### 环境踩坑
- pnpm 12：`onlyBuiltDependencies` 不再从 package.json 读取，须写在 `pnpm-workspace.yaml` 的 `allowBuilds`
- 沙箱内 esbuild postinstall 报 EBUSY（spawnSync 受限）→ 用 `pnpm install --ignore-scripts` 绕过，平台二进制 `@esbuild/win32-x64` 已随包安装，vitest 正常工作
- web tsconfig 不要同时引 `DOM` 与 `WebWorker` lib（全局声明冲突）；worker 里用 `globalThis as WorkerScopeLike` 代替 `self`
- `isolatedModules` 下 re-export 类型必须写 `export type`；联合类型上的 `Omit` 需写成分发式（`T extends unknown ? Omit<T,K> : never`）
- React `useSyncExternalStore` 的 getSnapshot 必须缓存对象引用，否则无限重渲染
